# People Tracking and Crowd Monitoring System

This project is a people tracking and crowd monitoring system developed using **YOLO11**, **BoT-SORT**, and **OpenCV**.

The system processes a video, detects people, assigns a unique tracking ID to each detected person, monitors a predefined polygon-based Region of Interest (ROI), counts the number of people inside the ROI, and displays an alert when the number of people exceeds the specified threshold.

## Features

- Person Detection using YOLO11
- Multi-Object Tracking using BoT-SORT
- Unique ID Assignment
- Polygon ROI Monitoring
- People Counting
- Crowd Alert System
- FPS Display
- Bounding Box Visualization

## Technologies

- Python
- YOLO11
- BoT-SORT
- OpenCV
- NumPy
- PyTorch
